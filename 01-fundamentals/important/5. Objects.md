## What is an Object?

An object is a data structure used to store related data as **key-value pairs**.

### 1. 🔥🔥🔥 How do you create an object?

You can create an object using **object literal syntax**.

### Simple Example

```js
const person = {
  name: "Ajay",
  age: 25,
};
```

Here, `name` and `age` are keys, and `"Ajay"` and `25` are their values.

**Remember:**

**Object → stores data as key-value pairs.**

---

### 2. 🔥🔥🔥 How do you access object properties?

You can access object properties using **dot notation** or **bracket notation**.

### Simple Example

```js
const person = {
  name: "Ajay",
  age: 25,
};

// Dot notation
console.log(person.name); // Ajay

// Bracket notation
console.log(person["age"]); // 25
```

**Remember:**

**Dot notation → `object.property`**

**Bracket notation → `object["property"]`**

---

### 3. 🔥🔥 What are Computed Properties?

Computed properties allow you to use the **value of a variable as an object property name**.

They are written using square brackets `[]`.

### Simple Example

```js
const key = "name";

const person = {
  [key]: "Ajay",
};

console.log(person.name); // Ajay
```

Here, the value of `key` (`"name"`) becomes the property name.

**Remember:**

**Computed property → use a variable or expression as the property name.**

### 1. 🔥🔥🔥 What is Object Destructuring?

Object destructuring is a way to **extract properties from an object and store them in variables**.

### Simple Example

```js
const person = {
  name: "Ajay",
  age: 25,
};

const { name, age } = person;

console.log(name); // Ajay
console.log(age); // 25
```

Here, `name` and `age` are extracted from the `person` object.

**Remember:**

**Object Destructuring → extract object properties into variables.**

---

### 2. 🔥🔥🔥 What is the Spread Operator?

The spread operator (`...`) is used to **expand the elements of an array or the properties of an object**.

### Simple Example

```js
const person = {
  name: "Ajay",
  age: 25,
};

const updatedPerson = {
  ...person,
  city: "Delhi",
};

console.log(updatedPerson);
```

Here, `...person` copies the properties of `person` into `updatedPerson`.

**Remember:**

**Spread (`...`) → expands or copies values/properties.**

---

### 3. 🔥🔥🔥 What is the Rest Operator?

The rest operator (`...`) is used to **collect multiple values into a single array or object**.

### Simple Example

```js
function add(...numbers) {
  console.log(numbers);
}

add(10, 20, 30);

// [10, 20, 30]
```

Here, `...numbers` collects all the arguments into an array.

**Remember:**

**Rest (`...`) → collects multiple values into one.**

### Easy Difference

**Spread → expands**

**Rest → collects**

### 🔥🔥 What is the difference between Spread and Rest?

Both use the same `...` syntax, but their purpose is different.

- **Spread** → expands values.
- **Rest** → collects values.

### Simple Example

```js
// Spread → expands
const numbers = [1, 2, 3];

const newNumbers = [...numbers, 4];

console.log(newNumbers); // [1, 2, 3, 4]
```

```js
// Rest → collects
function add(...numbers) {
  console.log(numbers);
}

add(1, 2, 3);

// [1, 2, 3]
```

### Quick Difference

| Spread `...`       | Rest `...`                      |
| ------------------ | ------------------------------- |
| Expands values     | Collects values                 |
| Used to copy/merge | Used to collect multiple values |
| `[...arr]`         | `(...args)`                     |

**Remember:**

**Spread → expands**

**Rest → collects**

### 1. 🔥🔥 What is `Object.keys()`?

`Object.keys()` returns an **array containing all the property names (keys)** of an object.

### Simple Example

```js
const person = {
  name: "Ajay",
  age: 25,
};

console.log(Object.keys(person));
// ["name", "age"]
```

**Remember:**

**`Object.keys()` → returns keys**

---

### 2. 🔥🔥 What is `Object.values()`?

`Object.values()` returns an **array containing all the property values** of an object.

### Simple Example

```js
const person = {
  name: "Ajay",
  age: 25,
};

console.log(Object.values(person));
// ["Ajay", 25]
```

**Remember:**

**`Object.values()` → returns values**

---

### 3. 🔥🔥 What is `Object.entries()`?

`Object.entries()` returns an **array containing key-value pairs** of an object.

Each key-value pair is returned as a separate array.

### Simple Example

```js
const person = {
  name: "Ajay",
  age: 25,
};

console.log(Object.entries(person));
// [["name", "Ajay"], ["age", 25]]
```

**Remember:**

**`Object.entries()` → returns key-value pairs**

### Easy Difference

**`Object.keys()` → keys**

**`Object.values()` → values**

**`Object.entries()` → keys + values**

### 🔥🔥🔥 How do you check whether a property exists in an object?

You can use the **`in` operator** or **`hasOwnProperty()`** to check whether a property exists in an object.

### Simple Example

```js
const person = {
  name: "Ajay",
  age: 25,
};

console.log("name" in person); // true
console.log("city" in person); // false
```

Using `hasOwnProperty()`:

```js
console.log(person.hasOwnProperty("name")); // true
console.log(person.hasOwnProperty("city")); // false
```

**Remember:**

**`in` → checks whether the property exists**

**`hasOwnProperty()` → checks whether the property belongs directly to the object**

### 1. 🔥🔥 What is the `in` operator?

The `in` operator is used to **check whether a property exists in an object**.

It returns `true` if the property exists and `false` if it does not.

### Simple Example

```js
const person = {
  name: "Ajay",
  age: 25,
};

console.log("name" in person); // true
console.log("city" in person); // false
```

**Remember:**

**`in` → checks whether a property exists in the object.**

---

### 2. 🔥🔥 What is `hasOwnProperty()`?

`hasOwnProperty()` is used to check whether a property **directly belongs to the object**.

It does not consider properties inherited from the object's prototype.

### Simple Example

```js
const person = {
  name: "Ajay",
};

console.log(person.hasOwnProperty("name")); // true
console.log(person.hasOwnProperty("toString")); // false
```

Here, `name` directly belongs to `person`, while `toString` is inherited.

**Remember:**

**`hasOwnProperty()` → checks whether the property directly belongs to the object.**

---

### 3. 🔥🔥 What is `Object.assign()`?

`Object.assign()` is used to **copy properties from one or more objects into another object**.

It returns the target object.

### Simple Example

```js
const person = {
  name: "Ajay",
};

const details = {
  age: 25,
};

Object.assign(person, details);

console.log(person);
// { name: "Ajay", age: 25 }
```

Here, the `age` property from `details` is copied into `person`.

**Remember:**

**`Object.assign()` → copies properties from one object to another.**

### 1. 🔥🔥 `Object.assign()` vs Spread Operator?

Both can be used to **copy properties from one object to another**, but their syntax and behavior are slightly different.

### Simple Example

```js
const person = {
  name: "Ajay",
  age: 25,
};

// Spread
const copy1 = { ...person };

// Object.assign()
const copy2 = Object.assign({}, person);

console.log(copy1); // { name: "Ajay", age: 25 }
console.log(copy2); // { name: "Ajay", age: 25 }
```

| `Object.assign()`                         | Spread `...`                                |
| ----------------------------------------- | ------------------------------------------- |
| `Object.assign({}, obj)`                  | `{ ...obj }`                                |
| Copies properties into a target object    | Creates a new object with copied properties |
| Can copy properties from multiple objects | Can combine multiple objects                |

**Remember:**

**`Object.assign()` → copies properties into a target object**

**Spread → creates a new object by expanding properties**

---

### 2. 🔥🔥 What is Property Shorthand?

Property shorthand is a shorter way to create an object property when the **property name and variable name are the same**.

### Simple Example

```js
const name = "Ajay";
const age = 25;

const person = {
  name,
  age,
};

console.log(person);
// { name: "Ajay", age: 25 }
```

Without shorthand:

```js
const person = {
  name: name,
  age: age,
};
```

With shorthand:

```js
const person = {
  name,
  age,
};
```

**Remember:**

**Property Shorthand → if key and variable name are the same, write the name only once.**

### 1. 🔥 What is Optional Property Access?

Optional property access uses the **optional chaining operator `?.`** to safely access a property when the object might be `null` or `undefined`.

Instead of throwing an error, it returns `undefined`.

### Simple Example

```js
const person = null;

console.log(person?.name); // undefined
```

Without `?.`:

```js
console.log(person.name); // Error
```

**Remember:**

**`?.` → safely access a property → returns `undefined` if the value is `null` or `undefined`.**

---

### 2. 🔥🔥 What is Object Destructuring with Default Values?

Object destructuring with default values allows you to **give a variable a default value when the property is `undefined`**.

### Simple Example

```js
const person = {
  name: "Ajay",
};

const { name, age = 25 } = person;

console.log(name); // Ajay
console.log(age); // 25
```

Here, `age` does not exist in the object, so the default value `25` is used.

**Remember:**

**Destructuring default → uses the default value when the property is `undefined`.**
