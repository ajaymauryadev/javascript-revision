## What is a Function?

A function is a reusable block of code that performs a specific task.

### 1. 🔥🔥🔥 What is a function?

A function is a reusable block of code that runs when it is called.

### Simple Example

```js
function greet() {
  console.log("Hello");
}

greet(); // Hello
```

Here, `greet()` is a function that prints `"Hello"` when it is called.

**Remember:**

**Function → reusable block of code that performs a task.**

---

### 2. 🔥🔥🔥 Function Declaration vs Function Expression?

**Function Declaration** defines a function using the `function` keyword with a function name.

**Function Expression** creates a function and stores it in a variable.

### Simple Example

```js
// Function Declaration
function greet() {
  console.log("Hello");
}

// Function Expression
const greet = function () {
  console.log("Hello");
};
```

### Main Difference

| Function Declaration                 | Function Expression                        |
| ------------------------------------ | ------------------------------------------ |
| Function is declared directly        | Function is assigned to a variable         |
| Can be called before its declaration | Cannot be called before its initialization |

**Remember:**

**Declaration → `function greet() {}`**

**Expression → `const greet = function() {}`**

### 1. 🔥🔥🔥 What is an Arrow Function?

An arrow function is a shorter way to write a function in JavaScript.

### Simple Example

```js
const greet = () => {
  console.log("Hello");
};

greet(); // Hello
```

**Remember:**

**Arrow Function → shorter syntax for writing a function.**

---

### 2. 🔥🔥🔥 Arrow Function vs Normal Function?

The main difference is how they handle **`this`**.

- **Normal function** → has its own `this`.
- **Arrow function** → does not have its own `this`; it uses `this` from its surrounding scope.

Arrow functions also have shorter syntax.

### Simple Example

```js
// Normal function
function greet(name) {
  return "Hello " + name;
}

// Arrow function
const greet = (name) => {
  return "Hello " + name;
};
```

**Remember:**

**Normal function → has its own `this`**

**Arrow function → inherits `this` from surrounding scope**

### 1. 🔥🔥🔥 What are Parameters and Arguments?

**Parameters** are variables written in the function definition that receive values.

**Arguments** are the actual values passed to the function when it is called.

### Simple Example

```js id="j2x0f7"
function greet(name) {
  console.log("Hello " + name);
}

greet("Ajay");
```

Here:

- `name` → **parameter**
- `"Ajay"` → **argument**

**Remember:**

**Parameter → variable in function definition**

**Argument → actual value passed to the function**

---

### 2. 🔥🔥 What are Default Parameters?

Default parameters allow us to give a parameter a **default value** when no argument is provided.

### Simple Example

```js id="x2c8r5"
function greet(name = "Guest") {
  console.log("Hello " + name);
}

greet(); // Hello Guest
greet("Ajay"); // Hello Ajay
```

Here, `"Guest"` is used when no argument is passed.

**Remember:**

**Default parameter → default value used when no argument is provided.**

## What is a Callback Function?

A callback function is a function that is **passed as an argument to another function and called by that function**.

### 1. 🔥🔥🔥 What is a Callback Function?

A callback function is a function passed to another function as an argument.

### Simple Example

```js
function greet(name, callback) {
  console.log("Hello " + name);
  callback();
}

function sayBye() {
  console.log("Bye");
}

greet("Ajay", sayBye);
```

Here, `sayBye` is passed to `greet()` and called inside it, so `sayBye` is a **callback function**.

**Remember:**

**Callback → function passed to another function.**

---

### 2. 🔥🔥🔥 What is a Higher-Order Function?

A higher-order function is a function that **takes another function as an argument or returns a function**.

### Simple Example

```js
function greet(name) {
  console.log("Hello " + name);
}

function processUser(name, callback) {
  callback(name);
}

processUser("Ajay", greet);
```

Here, `processUser()` takes `greet` as an argument, so `processUser()` is a **higher-order function**.

**Remember:**

**Higher-Order Function → takes a function or returns a function.**

## What is a Closure?

A closure is created when a function remembers and can access variables from its outer scope even after the outer function has finished executing.

### 1. 🔥🔥🔥 What is a Closure?

A closure is a function that **remembers variables from its outer scope**.

### Simple Example

```js
function outer() {
  let name = "Ajay";

  function inner() {
    console.log(name);
  }

  return inner;
}

const greet = outer();

greet(); // Ajay
```

Here, `inner()` remembers the `name` variable even after `outer()` has finished.

**Remember:**

**Closure → function remembers variables from its outer scope.**

---

### 2. 🔥🔥🔥 How does Closure work?

A closure works because the inner function keeps access to the variables from its outer scope.

### Simple Example

```js
function counter() {
  let count = 0;

  return function () {
    count++;
    console.log(count);
  };
}

const increment = counter();

increment(); // 1
increment(); // 2
increment(); // 3
```

Here, the returned function remembers `count`, so its value is preserved between calls.

**Remember:**

**Closure → inner function keeps access to outer variables.**

---

### 3. 🔥🔥🔥 What is Lexical Scope?

Lexical scope means a function can access variables based on **where the function is written in the code**.

### Simple Example

```js
let name = "Ajay";

function outer() {
  function inner() {
    console.log(name);
  }

  inner();
}

outer(); // Ajay
```

Here, `inner()` can access `name` because of where `inner()` is written in the code.

**Remember:**

**Lexical Scope → access depends on where the function is written.**

### 1. 🔥🔥 What is an IIFE?

IIFE stands for **Immediately Invoked Function Expression**.

It is a function that is **created and executed immediately**.

### Simple Example

```js id="2l7m3h"
(function () {
  console.log("Hello");
})();
```

Here, the function runs immediately after it is created.

**Remember:**

**IIFE → function that runs immediately.**

---

### 2. 🔥🔥 What is a Pure Function?

A pure function is a function that **always gives the same output for the same input** and does not change anything outside the function.

### Simple Example

```js id="w2l3q8"
function add(a, b) {
  return a + b;
}

console.log(add(2, 3)); // 5
console.log(add(2, 3)); // 5
```

Here, the same inputs always give the same output, and the function does not change anything outside itself.

**Remember:**

**Pure Function → same input → same output + no outside changes.**

---

### 3. 🔥🔥 What is an Impure Function?

An impure function is a function that **can produce different results for the same input or changes something outside the function**.

### Simple Example

```js id="j8f2kd"
let count = 0;

function increment() {
  count++;
  return count;
}

console.log(increment()); // 1
console.log(increment()); // 2
```

Here, the function changes the outside variable `count`, so it is an impure function.

**Remember:**

**Impure Function → depends on or changes something outside the function.**

### 🔥🔥 What is Recursion?

Recursion is a technique where a function **calls itself** to solve a problem step by step.

A recursive function must have a **base condition** to stop the function from calling itself forever.

### Simple Example

```js
function countDown(n) {
  if (n === 0) {
    return;
  }

  console.log(n);
  countDown(n - 1);
}

countDown(3);

// 3
// 2
// 1
```

Here, `countDown()` calls itself with a smaller value until `n` becomes `0`.

**Remember:**

**Recursion → a function calls itself until a stopping condition is reached.**

## What is the `this` Keyword?

The `this` keyword refers to the **object that is calling the function**. Its value depends on how the function is called.

### 1. 🔥🔥🔥 What is the `this` keyword?

`this` is a keyword that refers to the object associated with the current function call.

### Simple Example

```js
const person = {
  name: "Ajay",

  greet() {
    console.log(this.name);
  },
};

person.greet(); // Ajay
```

Here, `this` refers to the `person` object because `person` is calling `greet()`.

**Remember:**

**`this` → refers to the object that calls the function.**

---

### 2. 🔥🔥🔥 How is `this` determined?

The value of `this` is mainly determined by **how a function is called**, not where the function is written.

### Simple Example

```js
const person = {
  name: "Ajay",

  greet() {
    console.log(this.name);
  },
};

person.greet(); // Ajay
```

Here, `person` is calling `greet()`, so `this` refers to `person`.

**Remember:**

**`this` → determined by how the function is called.**

---

### 3. 🔥🔥🔥 `this` in a Regular Function vs Arrow Function?

- **Regular function** → `this` depends on how the function is called.
- **Arrow function** → does not have its own `this`; it uses `this` from its surrounding scope.

### Simple Example

```js
const person = {
  name: "Ajay",

  regular: function () {
    console.log(this.name);
  },

  arrow: () => {
    console.log(this.name);
  },
};

person.regular(); // Ajay
person.arrow(); // undefined
```

Here, the regular function gets `this` from `person`.

The arrow function does not create its own `this`.

**Remember:**

**Regular function → its own `this`**

**Arrow function → inherits `this` from surrounding scope**

### 1. 🔥🔥🔥 What is `this` inside an object method?

Inside an object method, `this` refers to the **object that called the method**.

### Simple Example

```js
const person = {
  name: "Ajay",

  greet() {
    console.log(this.name);
  },
};

person.greet(); // Ajay
```

Here, `person` calls `greet()`, so `this` refers to `person`.

**Remember:**

**Object method → `this` refers to the object calling the method.**

---

### 2. 🔥🔥 What is `this` inside a callback?

In a callback, `this` depends on **how the callback function is called**.

A regular callback function does not automatically get `this` from the function where it was passed.

### Simple Example

```js
const person = {
  name: "Ajay",

  greet() {
    setTimeout(function () {
      console.log(this.name);
    }, 1000);
  },
};

person.greet(); // undefined
```

Here, the regular callback function has its own `this` based on how it is called.

If we use an arrow function, it inherits `this` from the surrounding function.

```js
const person = {
  name: "Ajay",

  greet() {
    setTimeout(() => {
      console.log(this.name);
    }, 1000);
  },
};

person.greet(); // Ajay
```

**Remember:**

**Regular callback → `this` depends on how callback is called**

**Arrow callback → inherits `this` from surrounding scope**

### 🔥🔥 What happens when an object method is assigned to another variable?

When an object method is assigned to another variable, the function is copied **without its object reference**.

If the new variable calls the function normally, `this` no longer refers to the original object.

### Simple Example

```js
const person = {
  name: "Ajay",

  greet() {
    console.log(this.name);
  },
};

person.greet(); // Ajay

const greet = person.greet;

greet(); // undefined
```

Here, `person.greet()` is called as an object method, so `this` refers to `person`.

But `greet()` is called as a normal function, so it does not have `person` as its `this`.

**Remember:**

**Assigning a method to another variable → method loses the original object context.**

### 1. 🔥🔥🔥 What are `call()`, `apply()`, and `bind()`?

`call()`, `apply()`, and `bind()` are methods used to **control the value of `this`** when calling a function.

### Simple Example

```js
const person = {
  name: "Ajay",
};

function greet(age) {
  console.log(this.name, age);
}

greet.call(person, 25); // Ajay 25
greet.apply(person, [25]); // Ajay 25

const newGreet = greet.bind(person, 25);
newGreet(); // Ajay 25
```

Here, all three methods make `this` refer to `person`.

---

### 2. 🔥🔥🔥 Difference between `call()`, `apply()`, and `bind()`?

The main difference is **how arguments are passed and when the function runs**.

| Method    | Arguments    | Function runs |
| --------- | ------------ | ------------- |
| `call()`  | Individually | Immediately   |
| `apply()` | As an array  | Immediately   |
| `bind()`  | Individually | Later         |

### Simple Example

```js
function greet(age, city) {
  console.log(this.name, age, city);
}

const person = {
  name: "Ajay",
};

// call()
greet.call(person, 25, "Delhi");

// apply()
greet.apply(person, [25, "Delhi"]);

// bind()
const newGreet = greet.bind(person, 25, "Delhi");
newGreet();
```

**Remember:**

**`call()` → arguments separately + runs immediately**

**`apply()` → arguments in an array + runs immediately**

**`bind()` → returns a new function + runs later**

## What are First-Class Functions?

In JavaScript, functions are treated like **values**, which means they can be stored in variables, passed as arguments, and returned from other functions.

### 🔥🔥 What are First-Class Functions?

First-class functions mean that a function can be **stored in a variable, passed to another function, or returned from a function**.

### Simple Example

```js
const greet = function () {
  console.log("Hello");
};

// Passed as an argument
function execute(fn) {
  fn();
}

execute(greet); // Hello
```

Here, the function is stored in `greet` and then passed to `execute()` as an argument.

**Remember:**

**First-Class Functions → functions can be treated like values.**

### 🔥 What is Function Currying?

Function currying is a technique where a function that takes multiple arguments is converted into **a series of functions, where each function takes one argument**.

### Simple Example

```js
function add(a) {
  return function (b) {
    return a + b;
  };
}

const addFive = add(5);

console.log(addFive(3)); // 8
```

Here, `add(5)` takes the first argument and returns another function that takes the second argument.

**Remember:**

**Currying → one function with multiple arguments becomes a series of functions taking one argument at a time.**

### 🔥 What is Function Composition?

Function composition is a technique where the **output of one function is passed as the input to another function**.

### Simple Example

```js
const double = (x) => x * 2;

const addOne = (x) => x + 1;

const result = addOne(double(5));

console.log(result); // 11
```

Here:

- `double(5)` → `10`
- `addOne(10)` → `11`

So, the output of `double()` becomes the input of `addOne()`.

**Remember:**

**Function Composition → output of one function becomes input of another function.**
