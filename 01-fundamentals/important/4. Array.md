## 🔥🔥🔥 What is an Array?

An array is a data structure used to **store multiple values in a single variable**.

Array values are stored in order, and each value can be accessed using its **index**, starting from `0`.

### Simple Example

```js id="tw7q3m"
const fruits = ["Apple", "Mango", "Banana"];

console.log(fruits[0]); // Apple
console.log(fruits[1]); // Mango
```

Here:

- `"Apple"` → index `0`
- `"Mango"` → index `1`
- `"Banana"` → index `2`

**Remember:**

**Array → stores multiple values in one variable → accessed using index.**

### 1. 🔥🔥🔥 `map()` vs `forEach()`?

Both methods run a function for every element of an array, but their main purpose is different.

- **`map()`** → creates and returns a **new array**.
- **`forEach()`** → runs a function for each element but **does not return a new array**.

### Simple Example

```js
const numbers = [1, 2, 3];

const doubled = numbers.map((num) => num * 2);

numbers.forEach((num) => {
  console.log(num * 2);
});

console.log(doubled); // [2, 4, 6]
```

**Remember:**

**`map()` → transform → new array**

**`forEach()` → just perform an action**

---

### 2. 🔥🔥🔥 `map()` vs `filter()`?

- **`map()`** → changes each element and returns a new array.
- **`filter()`** → selects elements that satisfy a condition and returns a new array.

### Simple Example

```js
const numbers = [1, 2, 3, 4];

// map()
const doubled = numbers.map((num) => num * 2);

console.log(doubled); // [2, 4, 6, 8]

// filter()
const even = numbers.filter((num) => num % 2 === 0);

console.log(even); // [2, 4]
```

**Remember:**

**`map()` → transform every element**

**`filter()` → select matching elements**

---

### 3. 🔥🔥🔥 `map()` vs `reduce()`?

- **`map()`** → transforms every element and returns a new array.
- **`reduce()`** → combines all elements and returns a single result.

### Simple Example

```js
const numbers = [1, 2, 3, 4];

// map()
const doubled = numbers.map((num) => num * 2);

console.log(doubled); // [2, 4, 6, 8]

// reduce()
const total = numbers.reduce((sum, num) => sum + num, 0);

console.log(total); // 10
```

**Remember:**

**`map()` → array → new array**

**`reduce()` → array → single result**

### 🔥🔥🔥 `filter()` vs `find()`?

Both methods search an array based on a condition, but they return different results.

- **`filter()`** → returns **all matching elements** in a new array.
- **`find()`** → returns the **first matching element**.

### Simple Example

```js
const numbers = [1, 2, 3, 4, 5, 6];

const evenNumbers = numbers.filter((num) => num % 2 === 0);

console.log(evenNumbers); // [2, 4, 6]
```

```js
const firstEven = numbers.find((num) => num % 2 === 0);

console.log(firstEven); // 2
```

If no element matches:

```js
const result = numbers.find((num) => num > 10);

console.log(result); // undefined
```

**Remember:**

**`filter()` → all matching elements → array**

**`find()` → first matching element → single value**

### 🔥🔥🔥 `some()` vs `every()`?

Both methods check whether elements in an array satisfy a condition, but they check different things.

- **`some()`** → returns `true` if **at least one** element satisfies the condition.
- **`every()`** → returns `true` only if **all** elements satisfy the condition.

### Simple Example

```js
const numbers = [1, 2, 3, 4, 5];

const hasEven = numbers.some((num) => num % 2 === 0);

console.log(hasEven); // true
```

Here, at least one number is even, so `some()` returns `true`.

```js
const allPositive = numbers.every((num) => num > 0);

console.log(allPositive); // true
```

Here, all numbers are positive, so `every()` returns `true`.

**Remember:**

**`some()` → at least one matches**

**`every()` → all must match**

### 🔥🔥🔥 `slice()` vs `splice()`?

Both are array methods, but the main difference is that **`slice()` does not change the original array**, while **`splice()` changes the original array**.

- **`slice()`** → returns a portion of an array without changing the original array.
- **`splice()`** → adds, removes, or replaces elements and changes the original array.

### Simple Example

```js
const numbers = [1, 2, 3, 4, 5];

// slice()
const result = numbers.slice(1, 3);

console.log(result); // [2, 3]
console.log(numbers); // [1, 2, 3, 4, 5]
```

Here, `slice(1, 3)` takes elements from index `1` up to, but not including, index `3`.

```js
const numbers = [1, 2, 3, 4, 5];

// splice()
numbers.splice(1, 2);

console.log(numbers); // [1, 4, 5]
```

Here, `splice(1, 2)` removes `2` elements starting from index `1`.

| `slice()`                      | `splice()`                      |
| ------------------------------ | ------------------------------- |
| Does not change original array | Changes original array          |
| Used to get a portion          | Used to add, remove, or replace |
| Returns a new array            | Returns removed elements        |

**Remember:**

**`slice()` → copy a portion → original unchanged**

**`splice()` → modify array → original changed**

### 🔥🔥 `push()` vs `concat()`?

Both are used to add elements to an array, but the main difference is that **`push()` changes the original array**, while **`concat()` creates a new array**.

- **`push()`** → adds elements to the original array.
- **`concat()`** → combines arrays and returns a new array.

### Simple Example

```js
const numbers = [1, 2];

numbers.push(3);

console.log(numbers); // [1, 2, 3]
```

Here, `push()` changes the original array.

```js
const numbers = [1, 2];

const result = numbers.concat([3, 4]);

console.log(result); // [1, 2, 3, 4]
console.log(numbers); // [1, 2]
```

Here, `concat()` creates a new array without changing the original array.

**Remember:**

**`push()` → modifies original array**

**`concat()` → creates a new array**

### 1. 🔥🔥🔥 How does `sort()` work?

`sort()` is an array method used to **sort the elements of an array**.

By default, `sort()` converts elements to **strings** and sorts them based on their string values.

It **changes the original array**.

### Simple Example

```js
const fruits = ["Banana", "Apple", "Mango"];

fruits.sort();

console.log(fruits); // ["Apple", "Banana", "Mango"]
```

**Remember:**

**`sort()` → sorts the array and changes the original array.**

---

### 2. 🔥🔥🔥 Why does JavaScript `sort()` sometimes give unexpected results for numbers?

By default, `sort()` treats numbers as **strings**, so it sorts them alphabetically instead of numerically.

### Simple Example

```js
const numbers = [10, 2, 5, 1];

numbers.sort();

console.log(numbers); // [1, 10, 2, 5]
```

Here, JavaScript compares `"10"`, `"2"`, `"5"`, and `"1"` as strings.

To sort numbers correctly, provide a **comparison function**.

```js
const numbers = [10, 2, 5, 1];

numbers.sort((a, b) => a - b);

console.log(numbers); // [1, 2, 5, 10]
```

For descending order:

```js
numbers.sort((a, b) => b - a);
```

**Remember:**

**Default `sort()` → compares as strings**

**`sort((a, b) => a - b)` → numeric ascending order**

### 1. 🔥🔥 What is `includes()`?

`includes()` is an array method used to **check whether an array contains a specific value**.

It returns `true` if the value is found and `false` if it is not found.

### Simple Example

```js
const fruits = ["Apple", "Mango", "Banana"];

console.log(fruits.includes("Mango")); // true
console.log(fruits.includes("Grapes")); // false
```

**Remember:**

**`includes()` → checks whether a value exists → `true` or `false`**

---

### 2. 🔥🔥 `includes()` vs `indexOf()`?

Both can check whether a value exists in an array, but they return different results.

- **`includes()`** → returns `true` or `false`.
- **`indexOf()`** → returns the index of the value, or `-1` if it is not found.

### Simple Example

```js
const fruits = ["Apple", "Mango", "Banana"];

console.log(fruits.includes("Mango")); // true
console.log(fruits.indexOf("Mango")); // 1

console.log(fruits.includes("Grapes")); // false
console.log(fruits.indexOf("Grapes")); // -1
```

| `includes()`              | `indexOf()`           |
| ------------------------- | --------------------- |
| Returns `true` or `false` | Returns index or `-1` |
| Used to check existence   | Used to find position |
| Can correctly find `NaN`  | Cannot find `NaN`     |

**Remember:**

**`includes()` → "Does it exist?"**

**`indexOf()` → "Where is it?"**

### 1. 🔥🔥 What is `find()`?

`find()` is an array method used to **find the first element that satisfies a condition**.

It returns the **element itself**. If no element matches, it returns `undefined`.

### Simple Example

```js
const numbers = [1, 2, 3, 4, 5];

const result = numbers.find((num) => num > 2);

console.log(result); // 3
```

Here, `3` is the first number that satisfies the condition `num > 2`.

**Remember:**

**`find()` → first matching element → value**

---

### 2. 🔥🔥 What is `findIndex()`?

`findIndex()` is an array method used to **find the index of the first element that satisfies a condition**.

It returns the **index**. If no element matches, it returns `-1`.

### Simple Example

```js
const numbers = [1, 2, 3, 4, 5];

const result = numbers.findIndex((num) => num > 2);

console.log(result); // 2
```

Here, `3` is the first matching element, and its index is `2`.

**Remember:**

**`findIndex()` → first matching element → index**

### 🔥🔥 What is `reduce()` and where is it useful?

`reduce()` is an array method used to **combine all elements of an array into a single result**.

It is commonly used for calculating a total, finding a result, counting items, or building an object.

### Simple Example

```js
const numbers = [1, 2, 3, 4];

const total = numbers.reduce((sum, num) => {
  return sum + num;
}, 0);

console.log(total); // 10
```

Here, `reduce()` keeps adding each number to `sum` and finally returns one result: `10`.

### Where is `reduce()` useful?

- Calculating a **sum or total**
- Finding a **maximum or minimum value**
- Counting items
- Converting an array into an object
- Combining multiple values into one result

**Remember:**

**`reduce()` → array → single result**

### 1. 🔥🔥🔥 How do you remove duplicates from an array?

The easiest way is to use a **`Set`**, because a `Set` stores only unique values.

### Simple Example

```js
const numbers = [1, 2, 2, 3, 3, 4];

const uniqueNumbers = [...new Set(numbers)];

console.log(uniqueNumbers); // [1, 2, 3, 4]
```

Here, `Set` removes the duplicate values, and the spread operator converts it back into an array.

**Remember:**

**Remove duplicates → `new Set()`**

---

### 2. 🔥🔥🔥 How do you find duplicate elements?

We can use `filter()` with `indexOf()` to find elements that appear more than once.

### Simple Example

```js
const numbers = [1, 2, 2, 3, 3, 4];

const duplicates = numbers.filter((num, index) => {
  return numbers.indexOf(num) !== index;
});

console.log(duplicates); // [2, 3]
```

Here, if the current element's first index is different from its current index, it means the element appeared before.

**Remember:**

**Find duplicates → `filter()` + `indexOf()`**

### 1. 🔥🔥🔥 How do you flatten a nested array?

A nested array can be flattened using the **`flat()`** method.

### Simple Example

```js
const numbers = [1, [2, 3], [4, 5]];

const result = numbers.flat();

console.log(result); // [1, 2, 3, 4, 5]
```

For deeply nested arrays, we can use `flat(Infinity)`.

```js
const numbers = [1, [2, [3, [4]]]];

const result = numbers.flat(Infinity);

console.log(result); // [1, 2, 3, 4]
```

**Remember:**

**Flatten nested array → `flat()`**

---

### 2. 🔥🔥 What is `flat()`?

`flat()` is an array method used to **flatten nested arrays into a single array**.

By default, it flattens **one level**.

### Simple Example

```js
const numbers = [1, [2, 3], [4, 5]];

console.log(numbers.flat());
// [1, 2, 3, 4, 5]
```

**Remember:**

**`flat()` → removes one level of array nesting by default.**

---

### 3. 🔥🔥 What is `flatMap()`?

`flatMap()` is a combination of **`map()` + `flat()`**.

It maps each element and then flattens the result by **one level**.

### Simple Example

```js
const numbers = [1, 2, 3];

const result = numbers.flatMap((num) => [num, num * 2]);

console.log(result);
// [1, 2, 2, 4, 3, 6]
```

Here, `flatMap()` first creates arrays using `map()` and then flattens them by one level.

**Remember:**

**`flatMap()` → `map()` + one-level `flat()`**

### 1. 🔥🔥 How do you reverse an array?

You can use the `reverse()` method to reverse the elements of an array.

`reverse()` **changes the original array**.

### Simple Example

```js
const numbers = [1, 2, 3, 4, 5];

numbers.reverse();

console.log(numbers); // [5, 4, 3, 2, 1]
```

**Remember:**

**`reverse()` → reverses the array → changes the original array**

---

### 2. 🔥🔥 How do you merge two arrays?

You can use the **spread operator (`...`)** or `concat()` to merge two arrays.

### Simple Example

```js
const arr1 = [1, 2, 3];
const arr2 = [4, 5, 6];

const result = [...arr1, ...arr2];

console.log(result); // [1, 2, 3, 4, 5, 6]
```

Here, a new array is created and the original arrays are not changed.

**Remember:**

**Merge arrays → `[...arr1, ...arr2]`**

### 🔥🔥 What is the difference between Mutable and Immutable Array Methods?

**Mutable array methods** change the **original array**.

**Immutable array methods** do **not change the original array**. They return a new array or value instead.

### Simple Example

```js
// Mutable
const numbers = [1, 2, 3];

numbers.push(4);

console.log(numbers); // [1, 2, 3, 4]
```

Here, `push()` changes the original array.

```js
// Immutable
const numbers = [1, 2, 3];

const newNumbers = numbers.map((num) => num * 2);

console.log(numbers); // [1, 2, 3]
console.log(newNumbers); // [2, 4, 6]
```

Here, `map()` does not change the original array.

### Common Examples

**Mutable methods:**
`push()`, `pop()`, `shift()`, `unshift()`, `splice()`, `sort()`, `reverse()`

**Immutable methods:**
`map()`, `filter()`, `slice()`, `concat()`, `includes()`, `find()`, `some()`, `every()`

**Remember:**

**Mutable → changes original array**

**Immutable → does not change original array**

### 🔥🔥 How do you sort an array of objects?

You can sort an array of objects using `sort()` with a **comparison function** that compares a specific property of each object.

### Simple Example

```js
const users = [
  { name: "Ajay", age: 30 },
  { name: "Rahul", age: 25 },
  { name: "Amit", age: 28 },
];

users.sort((a, b) => a.age - b.age);

console.log(users);
```

This sorts the users by `age` in **ascending order**.

For descending order:

```js
users.sort((a, b) => b.age - a.age);
```

For strings:

```js
users.sort((a, b) => a.name.localeCompare(b.name));
```

**Remember:**

**Array of objects → `sort()` + compare the required property.**

### 🔥🔥 How do you find the maximum/minimum value in an array?

You can use `Math.max()` and `Math.min()` with the **spread operator (`...`)** to find the maximum and minimum values.

### Simple Example

```js
const numbers = [10, 5, 20, 8, 15];

const max = Math.max(...numbers);
const min = Math.min(...numbers);

console.log(max); // 20
console.log(min); // 5
```

Here, `...numbers` passes the array elements as separate arguments to `Math.max()` and `Math.min()`.

**Remember:**

**Maximum → `Math.max(...array)`**

**Minimum → `Math.min(...array)`**
